# Counting Sort - Java

A simple Java program to sort an array using the Counting Sort algorithm.

## Features
- Takes array elements from the user
- Counts the occurrences of each element
- Sorts the elements in ascending order
- Displays the sorted array

## Technology Used
Java

## DSA Topic
Sorting - Counting Sort

## Output

Enter number of elements: 6
Enter elements:
4 2 2 8 3 3

Sorted array:
2 2 3 3 4 8
